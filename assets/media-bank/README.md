# Korover Lab media bank

Candidate images (physics plots, illustrations, photos) for the lab website. Nothing here is on the site until it is copied into `assets/images/`.

The licence column records what was stated at the source (`not checked` or `unverified` where nothing was found). The lab uses this material under non-profit fair use.

## Layout

- `manifest.csv`: one row per item (file, topic, type, title, caption, source paper, URL, figure number, credit, licence, notes).
- `index.html`: contact sheet (open locally, no external resources).
- `plots/<topic>/`, `illustrations/<topic>/`, `photos/<topic>/`: web-ready files (plots about 1600 px, photos about 2400 px).
- `originals/`: vector PDFs of plots and full-resolution photos where the source had them.

Topics: src, emc, gluons, nucleon-3d, eic, experiments, tau. Figure numbers refer to the arXiv version where noted. Captions are shortened from the source caption; where the source gave none, the caption is a description and the notes say so.
